Reading the cost tags.
  • Low — a shared @keyframes anim-<val> and a registry entry. Nothing else, per the preset-registry contract in render-runtime.js.
  • Medium — needs an extra DOM node or per-id keyframes baked from element props, so it touches buildElementKeyframesCSS and every preview surface.
  • High — needs JS in the exported runtime, plus new props in the panel.
  • Text only — meaningless on shapes and images, so it'd be filtered like the existing textOnly presets.
